# Creative Experiments

This repo is the execution layer.
Each experiment is a folder with:
- brief
- plan
- launch details
- results
- postmortem
- assets

## Create a new experiment
Copy `experiments/_TEMPLATE/` and rename it:
`YYYY-MM-DD_{FUNNEL}-{FORMAT}-{ANGLE}_{hook}_v{n}`

Example:
`2026-02-22_TOF-STATIC-PAIN_competitor-behind_v1`
